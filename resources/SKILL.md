# SUSTech Resources

External resources for SUSTech-related lookup.

## sustech.online (南科手册)
**https://sustech.online/** — Community student handbook maintained by SUSTech students. Provides quick access to official portals and student-contributed guides.

### Common portals
| Link | Notes |
|------|-------|
| [官网](https://www.sustech.edu.cn/) | SUSTech official site |
| [图书馆](https://lib.sustech.edu.cn/) | Library portal |
| [邮箱](https://mail.sustech.edu.cn) | Student email |
| [服务大厅](https://ehall.sustech.edu.cn/new/index.html) | eHall service desk |
| [Sakai](https://sakai.sustech.edu.cn) | Sakai LMS |

| [校园卡二维码](https://campuscard.sustech.edu.cn/epay/thirdconsume/qrcode) | Campus card QR |

### Campus tools (sustech.online sub-pages)
- **`/transport/bustimer`** — Live bus schedules and shuttle vehicle positions
- **`/facility/`** — Interactive campus street view with stops, printers, stores
- **`study/talks/`** — Recent campus lectures and talks

### Course reviews
- **[NCES 牛娃课程评价](https://ncesnext.com/)** — Course reviews + syllabus lookup. Requires SUSTech email to register.

### Freshman guides
- **`/if-you-are-a-freshman/`** — Quickstart guides by year
- **书院新生手册 PDFs** —致诚, 致仁书院 published handbooks (PDFs on sustech.online mirrors)
- **[飞跃手册](https://sustech-application.com)** — Study abroad + job application experiences from seniors

### Maps
- **[校园地图 PDF](https://mirrors.sustech.edu.cn/site/sustech-online/documents/campus-map/%E5%8D%97%E6%96%B9%E7%A7%91%E6%8A%80%E5%A4%A7%E5%AD%A6%E6%A0%A1%E5%9B%AD%E5%9C%B0%E5%9B%BE-v4-1.pdf)** — Vector campus map v4.1 (Oct 2025), via SUSTech mirrors. Includes bus routes, printers, stores.
