# Blackboard (BB)

Course materials, assignments, announcements.

## Login

Use the login script — it opens CAS, Chrome autofills credentials, presses Enter:

```bash
cd ~/.openclaw/workspace/skills/sustech-survival/bb && ./login-bb.sh
```

## Verify Login

```bash
cd ~/.openclaw/workspace/skills/sustech-survival/bb && ./check-login.sh
```

Expected URL when logged in: `https://bb.sustech.edu.cn/webapps/portal/execute/tabs/tabAction?tab_tab_group_id=_1_1`
